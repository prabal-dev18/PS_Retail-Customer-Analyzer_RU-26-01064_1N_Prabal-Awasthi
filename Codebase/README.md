Retail Customer Analyzer

Project Overview

Retail Customer Analyzer is a Python-based project that analyzes retail customer spending data using Pandas. It provides useful statistical insights and helps understand customer spending patterns.

Objectives

- Analyze customer spending data.
- Calculate mean and median spending.
- Identify highest and lowest spending customers.
- Filter customers based on minimum spending.
- Generate city-wise spending summaries.
- Handle invalid user inputs.

Technologies Used

- Python
- Pandas
- CSV (Comma Separated Values)

How to Run the Project

1. Install Python.
2. Install Pandas using:

pip install pandas

3. Open the project folder in VS Code.
4. Run the following command:

python retail_analyzer.py

5. Enter the required minimum spending amount when prompted.

Key Features

1. Customer data analysis.
2. Mean and median calculation.
3. Highest and lowest spending identification.
4. Minimum spending filter.
5. City-wise analysis.
6. Input validation.
