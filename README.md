1. Project Overview

Retail Customer Analyzer is a Python-based data analysis project designed to analyze retail customer information using a CSV dataset.

The project uses Python and the Pandas library to process customer records, calculate spending statistics, identify high-value customers, and analyze city-wise spending patterns.

It provides a simple menu-driven interface that allows users to perform different customer data analysis operations.

2. Objectives

- To understand and analyze retail customer data.
- To calculate important statistical measures.
- To identify high-value customers based on spending.
- To analyze customer spending across different cities.
- To practice Python programming and data handling using Pandas.

3. Technologies Used

- Programming Language: Python
- Library: Pandas
- Data Format: CSV (Comma-Separated Values)
- Development Environment: Visual Studio Code
- Platform: GitHub

4. Project Features

1. Spending Statistics

- Calculates total customer spending.
- Calculates mean spending.
- Calculates median spending.
- Displays basic spending statistics.

2. High-Value Customer Analysis

- Accepts a minimum spending amount from the user.
- Filters customers based on their spending.
- Displays customers whose spending meets the entered threshold.

3. City-Wise Spending Analysis

- Groups customer records according to their city.
- Calculates spending for different cities.
- Displays city-wise spending information.

7. How to Run the Project

Follow these steps to execute the project:

1. Download or clone this repository.
2. Make sure Python is installed on your system.
3. Install the required Pandas library.

pip install pandas

4. Keep "customers.csv" and "retail_analyzer.py" in the same folder.
5. Open the project folder in Visual Studio Code.
6. Run the following command in the terminal:

python retail_analyzer.py

7. Follow the menu displayed in the terminal and select the desired operation.
